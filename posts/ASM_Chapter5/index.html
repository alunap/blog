Chapter 5 of Applied Statistical Modelling for Ecologists, by Marc Kéry and Kenneth Kellner, focuses on Ordinary Linear Regression. This chapter also gets in the interesting subject of Posterior Predictive Checks and Goodness Of Fit.

In this chapter, we use a simulated dataset about wallcreepers (which we don’t have in the UK, grrrh). I guess this is very familiar to most people. If the value of our dependent variable \(y_i\) varies according to independent variable \(x_i\), then \[\mu = \alpha + \beta\cdot x_i\] We take this to deterministic, linear part to be the mean, or expected value. \[y_i\sim{Normal(\alpha + \beta\cdot x_i, \sigma^2)}\] We can also express this as a linear equation for the mean plus an error term. \[y_i = \alpha + \beta\cdot x_i + \epsilon_i\] \[\epsilon_i\sim{Normal(0, \sigma^2)}\] So, we have an overall intercept, a coefficient for the effect of x, which will be a regression line, and some scatter around that line which is normally distributed but centered on the line itself.

5.3.3 Computing Predictions

Next we get the predictions from the model. In this case there is an identity link function, so the prediction come directly from the linear predictor without any transformation. That is, \(\hat{y} = \alpha + \beta x_i\).

Note

Kéry & Kellner’s R code manually calculates the interval using 1.96 (pred$fit - 1.96 * pred$se.fit). That is an asymptotic approximation (assuming infinite degrees of freedom). Julia’s predict(…, interval=:confidence) uses the exact Student’s t-distribution critical value based on the model’s actual residual degrees of freedom. This means Julia’s frequentist ribbon will be slightly more statistically strictly correct than the manual 1.96 calculation in the ASM book (though practically, with enough data points, the visual difference is negligible).

using DataFrames

# Create a dense grid of x-values for prediction
xpred = range(1, 16, length=100)
newdata = DataFrame(x = xpred)

# Get predictions and 95% Confidence Intervals directly
# GLM returns a DataFrame with columns: :prediction, :lower, and :upper
preds = predict(model, newdata, interval=:confidence, level=0.95)

# Assemble the equivalent of pred.table
pred_table = DataFrame(
    x = newdata.x,
    point_est = preds.prediction,
    LCL = preds.lower,
    UCL = preds.upper

5.4 Bayesian Analysis

We will translate the JAGS version of the linear regression model into a Bayesian analysis using Julia’s Turing package. Now we start to see some major differences between the way you would approach this in BUGS/JAGS and how you do it in Turing (or more generally using a HMC/NUTS sampler).

In the JAGS code, you put everything into the model block, including priors, likelihood, posterior predictive checks, derived residuals, etc. In Turing, this would break the NUTS sampler. In JAGS, the model string is a scripting language telling JAGS what nodes to track during its Gibbs sampling loops. In Turing, the @model macro defines a strict probabilistic log-density target for the sampler. Everything else, residuals, fit statistics, predictive datasets, etc, is just standard Julia code applied to the resuling DataFrame or Chain. Since Julia is fast, we don’t have to convert this into a different language such as C++.

NB the @. macro at the start of a statement just means to broadcast each of the operations element-wise over arrays. You can also, (and you see I do) just add the . broadcast operator for each one.

Note

The Turing philosophy is: fit the parameters in the model, generate predictions outside the model.

using Turing, FlexiChains, MCMCDiagnosticTools

@model function linear_regression(x, y)
  # Priors. tau = 0.0001 is sd = 100
    α ~ Normal(0, 100)
    β ~ Normal(0, 100)
    σ ~ Uniform(0, 100)

  # Likelihood
    μ = @. α + β * x
    y ~ product_distribution(Normal.(μ, σ))
end

model = linear_regression(x, y)
chains = sample(model, NUTS(), MCMCThreads(), 10000, 4; progress=false)
summarystats(chains)

5.4.2 GOF and Posterior Predictive Checks


# Extract parameter vectors from the chain
α_post = vec(Array(chains[:α]))
β_post  = vec(Array(chains[:β]))
σ_post = vec(Array(chains[:σ]))

S = length(α_post) # Number of posterior draws
fit = zeros(S)         # Sum of squares for actual data
fit_new = zeros(S)     # Sum of squares for new data

# Generate y.new and compute discrepancies for every posterior draw
for s in 1:S
    # 1. Expected values for this iteration
    μ = @. α_post[s] + β_post[s] * x
    
    # 2. Generate replicate dataset
    y_new = rand.(Normal.(μ, σ_post[s]))
    
    # 3. Calculate squared residuals
    fit[s]     = sum((y .- μ).^2)
    fit_new[s] = sum((y_new .- μ).^2)
end

# Calculate the Bayesian p-value (proportion of times fit_new > fit)
bp_val = mean(fit_new .> fit)
println("Bayesian p-value: ", round(bp_val, digits=3))
Bayesian p-value: 0.555

As with the book, we have a value close to 0.5, so a decent fit.

Finally, we will plot the Credible Intervals (CRI) like figure 5.4 in the book. First obtain predictions and calculate offset distances for the plot ribbon. Note that in R the plots are built using polygon and absolute values. In Julia we use the ribbon command and provide the lower and upper offsets relative to the mean prediction.

using Statistics

# Matrix of predictions: rows = length(xpred), cols = number of MCMC draws
predictions = [α_post[s] + β_post[s] * xp for xp in xpred, s in 1:length(α_post)]

# Calculate Bayesian point estimates (post. means) and 95% CRI
BPE = vec(mean(predictions, dims=2))
LPB = [quantile(row, 0.025) for row in eachrow(predictions)]
UPB = [quantile(row, 0.975) for row in eachrow(predictions)]

# Calculate offset distances required by Plots.jl 'ribbon'
BPE_rib_lower = BPE .- LPB
BPE_rib_upper = UPB .- BPE

5.7 Maximum Likelihood Estimation

First, we will do a more-or-less direct translation of the R code for maximum likelihood estimation into Julia.

using Optim, Turing
using Distributions

# Define the NLL function
function NLL(params, y, x)
    α = params[1]
    β  = params[2]
    σ = exp(params[3]) # convert from log scale
    n = length(y)

    # Vectorized calculation using Julia's broadcasting dot (.) syntax
    μ = @. α + β * x
    LL = logpdf.(Normal.(μ, σ), y)
    
    return -sum(LL)
end

# Minimize the NLL to find MLEs
inits = [0.0, 0.0, 0.0]

# Wrap NLL in a function so Optim only sees `params`
objective(params) = NLL(params, y, x)

# Run optimization using BFGS
# Autodiff is optional but highly recommended in Julia for exact gradients
out5_7 = optimize(objective, inits, BFGS(), autodiff = AutoForwardDiff())

# Extract parameters
# Optim.minimizer returns the optimal parameters
diy_params = Optim.minimizer(out5_7)

diy_est = [
    diy_params[1],        # alpha
    diy_params[2],        # beta
    diy_params[3]         # log.sigma
]
